# skills-github-pages

GitHub Skills の学習コース「[GitHub Pages](https://github.com/skills/github-pages)」を進めるために作成した学習用リポジトリです。

GitHub Pages と Jekyll を使って、リポジトリからサイトを公開する手順を練習します。

## 構成

- `.github/steps/` — コース各ステップの説明
- `.github/workflows/` — ステップ進行を自動化する GitHub Actions

## 進捗

Step 1(GitHub Pages の有効化)まで実施。
